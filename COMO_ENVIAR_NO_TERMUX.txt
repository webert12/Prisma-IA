PRISMA IA v8 — PUBLICAÇÃO PELO TERMUX

1. Baixe o ZIP e extraia o conteúdo completo na pasta Download do celular.
2. No Termux, copie e cole o bloco abaixo:

termux-setup-storage
pkg install unzip git -y
cd ~/storage/shared/Download || exit 1
unzip -o prisma_ia_saas_profissional_v8.zip -d ~/storage/shared/Download || exit 1
cd ~/storage/shared/Download || exit 1
bash atualizar_github_termux.sh

O script usa a pasta prisma_ia_saas_profissional_v8 e envia para https://github.com/webert12/Prisma-IA.

IMPORTANTE: para ativar o Financeiro sincronizado, abra supabase/schema.sql no SQL Editor do seu projeto Supabase e execute. Depois, em Render > Environment, configure SUPABASE_URL e SUPABASE_ANON_KEY com os dados do projeto Supabase. Mantenha GEMINI_API_KEY e GEMINI_MODEL configuradas. Nunca envie chaves privadas ao GitHub.
